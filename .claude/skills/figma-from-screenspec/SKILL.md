# 画面スペック → Figma組み立て

> **空の雛形（C-0時点）**: この工程は C-2（Figmaコンポーネントライブラリ整備）が前提。
> C-2 完了後に中身を詰める。

## 原則（先に確定している方針のみ）

- 確立済みコンポーネント・トークン（Figma Variables）**のみ**を使う
- 新しい色・サイズ・コンポーネントを発明しない
- コンポーネントで表現できない要素があれば止めて報告する
- 生成物は叩き台。人間レビューを必ず挟む
