# Confluence設計 → 画面スペック 変換

> **雛形（C-0時点）**: 詳細手順は C-3（Confluence→Figma生成）着手時に詰める。
> 現時点では骨子のみを定義する。

## 前提

- cloudId: `91ae6d4d-2dee-4ec6-beb1-da91884ef1aa`
- 親ページ: 「カップル家計簿アプリ構想」pageId `6291465`
- Atlassian MCP の `getConfluencePage` 等で読み取る

## 手順（骨子）

1. 指定 pageId のページ本文を取得する（子ページが必要なら descendants も確認）
2. 設計の記述から「画面」に関する要件を抽出する
3. 下記フォーマットの画面スペックに構造化する
4. ページに書かれていないことは推測で埋めず「未決」として列挙する

## 出力フォーマット（骨子）

```markdown
# 画面スペック: <画面名>
- 元ページ: <pageId / タイトル>

## 要素（UI構造）
- <要素の階層リスト>

## データ
| 要素 | データ | 出所（テーブル/集計） |

## 状態
- 空状態 / ローディング / エラー / 件数バリエーション

## 遷移
- <トリガー> → <遷移先 / モーダル>

## 未決
- <設計ページに書かれていない/曖昧な点>
```
